# 亚马逊选品调研 Skill

面向电商运营，把“这个品类能不能做”拆成三个好回答的问题：**哪些规格有人买、跟谁竞争、产品还能改进什么。**

维护者：Hao Wu · 状态：active · 当前版本：1.1.0 · 更新：2026-10-22

## 用起来

将本仓库作为一个Skill安装。在Codex中可将仓库克隆到技能目录（该路径须尚不存在）：

```bash
git clone https://github.com/haoneowu/amazon-selection-research-skill.git ~/.codex/skills/amazon-selection-research
```

然后在能加载该Skill的新会话中说：

> 用 $amazon-selection-research 调研美国站可机洗地毯，帮我找到值得验证的规格和价格带。

Skill会先检查：

- **Bright Data MCP**：用于采集商品、榜单及可获取的评论信息。
- **飞书 CLI**：用于写入报告。
- **你指定的飞书知识库目录链接**：决定报告放在哪里。

不会配置也可以直接说“我还没配好”，它会按当前缺失项一步步引导。已有连接会复用，密钥不需要发进聊天。详细配置入口见[配置引导](references/setup.md)。

## 你会得到什么

- 规格与价格带的需求证据、关键竞争商品、评价积累和产品定位。
- 用户负面反馈对应的产品与Listing改进方向，以及进入条件。
- 同一知识库目录下的文字报告和易读HTML文件：核心结论直接显示，长解释默认折叠。

已有报告可继续补充和刷新，保留链接及版本记录。HTML是文件交付，能否在飞书直接预览取决于飞书环境，不承诺网页托管。

## 使用边界

这是一份Agent工作流，不是独立采集软件。需要宿主提供文件／命令执行、MCP工具及相应授权；浏览器和子Agent用于更完整的UI与独立复核，缺少时会说明验证范围。无需安装其他私人Skill。

购买徽标不等于精确月销量；平台负面主题不等于美国差评率。证据不足时保留条件候选，不编造市场份额、利润或“爆款”结论。Bright Data和飞书的账号、服务费用与权限由使用者自行配置；本仓库不附带账户、原始业务数据或客户报告。

## 阅读质量如何保证

Skill包含可直接运行的结构化HTML渲染器和虚构示例。作者先把研究组织为结论、要点、规格价格图、竞品对照与问题改进链，再渲染页面；长解释默认折叠，全量商品进入附录。有助理解时配产品、场景或结构插图，标清来源或示意性质。文字版同样要求bullet、表格和图表，不能只是HTML好看。

详见[可读性合同](references/readability.md)与[内容模型](references/report-schema.md)。结构检查不能替代真实阅读审核：必须查看需求、竞争、用户问题章节，并实测桌面／窄屏。
